# MarkdownViewer

<script>
  if (!location.search.includes("lang=")) {
    var lang = (navigator.language || "en").toLowerCase();
    if (lang.startsWith("ko")) {
      location.replace("HELP.ko.html");
    } else {
      location.replace("HELP.en.html");
    }
  }
</script>

A native markdown viewer for macOS — open a file and it renders
immediately, with in-place editing, live Mermaid diagrams, inline SVG,
GitHub round-tripping, and export to PDF/HTML/Word/Markdown/draw.io.

macOS용 네이티브 마크다운 뷰어입니다 — 파일을 열면 바로 렌더링되고, 그
자리에서 편집, 실시간 Mermaid 다이어그램, 인라인 SVG, GitHub 연동, PDF/
HTML/Word/Markdown/draw.io 내보내기까지 지원합니다.
